# アイテム画像の置き場所

部位（種類がある部位は種類）ごとのフォルダに画像を置くと、コーデ登録画面の選択肢に自動で追加されます。

| フォルダ | 部位 | 種類 |
|---|---|---|
| `hair/` | ヘアスタイル | |
| `hair-accessory/` | ヘアアクセサリー | |
| `head-accessory/` | ヘッドアクセサリー | |
| `mask/` | マスク | |
| `face-accessory/` | フェイスアクセサリー | |
| `necklace/` | ネックレス | |
| `cape/` | ケープ | |
| `outfit/no-shoes/` | パンツ | パンツ（靴なし） |
| `outfit/shoes/` | パンツ | パンツ（靴あり） |
| `shoes/` | シューズ | |
| `prop/instrument/` | 持ち歩きアイテム | 楽器 |
| `prop/large/` | 持ち歩きアイテム | 大きい持ち物 |
| `prop/small/` | 持ち歩きアイテム | 小さい持ち物 |

部位や種類の名前・構成は `src/types.ts` の `PARTS` で定義しています。

## ルール

- 対応形式: png / jpg / jpeg / webp / gif / svg
- **ファイル名（拡張子を除く）がそのままアイテム名**になります
  - 例: `cape/光の翼ケープ.png` → 「光の翼ケープ」
- 先頭に `01_` のような番号を付けると、その順に並びます（番号は表示されません）
  - 例: `cape/01_光の翼ケープ.png`
- 保存済みのコーデはファイル名で画像を参照しています。**ファイル名を変えたり消したりすると、そのコーデでは「削除済み」と表示されます**
- 種類のフォルダ名はアイテム id に含まれません。**同じ部位の中で種類のフォルダを移し替えても、保存済みのコーデはそのまま**です（そのため、同じ部位の中では、種類が違っても同じファイル名は使えません）
- 正方形で背景が透明な画像（128px 前後）にすると、きれいに表示されます

## アイテム情報（任意）

`src/data/item-info/*.json` に、検索・絞り込み用の情報（靴あり／なし、入手元、季節、染色可否、コスト、効果など）を書けます。ファイルは何個に分けても構いません（例: 持ち歩きアイテムは `prop-instrument.json` / `prop-large.json` / `prop-small.json`）。
キーはアイテム id（`<部位>/<ファイル名(拡張子なし)>`。種類のフォルダ名は含まない。例: `outfit/010_海月の語り部`）なので、**画像のファイル名を変えたら JSON のキーも合わせて変更**してください。
